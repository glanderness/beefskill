# BeefSkill 架构

BeefSkill 是一个两层系统：根目录的 `beefskill` 负责识别当前任务并路由；`skills/` 中的叶子目录负责完成一个边界清晰的具体任务。

```text
用户问题
  ↓
beefskill 总入口
  ├── AI 产品与增长
  └── 个人 AI 自媒体
        ↓
      一个已发布的子 Skill
```

## 两条主线

| 主线 | 解决的问题 | 不承担的职责 |
| --- | --- | --- |
| AI 产品与增长 | 产品机会、需求验证、产品包装、获客、转化、留存 | 不替用户凭空证明需求或编造增长结果 |
| 个人 AI 自媒体 | 内容资产、个人定位、连续发布、内容产品化 | 不用换标题代替新选题，也不编造个人经历 |

## 架构约束

- `catalog/skills.yaml` 是已发布 Skill 的唯一目录；总入口只路由其中标为 `stable` 的条目。
- 每个可调用的子 Skill 都必须位于独立目录，并包含自己的 `SKILL.md`。
- 领域目录只用于分类，不作为万能 Skill 调用。
- 一个子 Skill 只解决一个核心任务；需要组合时由总入口选择一个主 Skill 和最多一个辅助 Skill。
- 子 Skill 的参考资料、示例和 UI 元数据跟随该 Skill 存放，避免跨模块隐式依赖。
