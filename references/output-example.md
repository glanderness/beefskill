# 标准输出示例

## 输入摘要

用户准备从零运营小红书，并用 Codex、TikHub 和飞书 CLI 搭建了一个对标素材库。系统可以分析视频内容与作者信息，未来准备继续增加风格、节奏和文案分析能力。

## 一、可以继续利用的内容资产

| 内容资产 | 可延伸方向 |
|---|---|
| 准备从零运营小红书 | 起号计划、阶段目标、过程复盘 |
| 起号前先研究对标 | 选择标准、研究方法、常见误区 |
| 搭建对标素材库 | 完整流程、数据结构、实际使用 |
| 三种工具协同工作 | 工具分工、选择依据、工作流程 |
| 后续增加分析能力 | 功能优先级、判断标准、实际验证 |

## 二、最值得先写的三个选题

### 选题一：从零做小红书，我为什么没有直接发内容，而是先建了一个对标素材库

- 推荐理由：这个选题面向所有准备起号的人，不要求读者理解具体工具。它先解释为什么要做这套系统，为后续的方法和工具内容建立背景。
- 建议结构：准备从零起号 → 直接发布内容可能遇到的问题 → 为什么先研究对标 → 素材库要解决的三个问题 → 接下来如何验证。

### 选题二：我把一条小红书视频链接交给系统后，整个分析流程是怎样运行的

- 推荐理由：这是目前真实素材最充分、最容易写具体的一篇。它能把功能介绍进一步变成读者可以理解的完整工作流程。
- 建议结构：输入视频链接 → 获取视频信息 → 分析标题、封面和文案 → 整理作者信息 → 写入飞书 → 人工检查 → 使用分析结果。

### 选题三：我怎么决定一条小红书视频到底应该分析哪些信息

- 推荐理由：这是独特性最强的元方法内容。重点不再是展示系统有哪些功能，而是解释如何判断哪些信息值得长期记录和分析。
- 建议结构：最初准备分析什么 → 为什么字段不是越多越好 → 每个字段对应什么决策 → 暂时舍弃了什么 → 当前最小字段集合 → 后续如何调整。

## 三、按照三层框架继续延伸

### 内容层：围绕这件事本身

1. 从零做小红书，我为什么先研究对标，而不是直接发布内容
2. 什么样的小红书账号才值得成为对标
3. 对标素材库和普通收藏夹到底有什么区别
4. 为什么不能只看单条热门视频，还要持续观察作者账号
5. 如何用对标素材库确定第一批内容方向

### 方法层：这套系统怎么做

1. 用三个工具搭建小红书对标素材库的完整流程
2. 三个工具在整个系统中分别负责什么
3. 一条视频链接进入系统后，会经过哪些处理步骤
4. 飞书对标素材库应该设计哪些核心字段
5. 如何把素材库中的分析结果转化成自己的选题

### 元方法层：你怎么形成这套做法

1. 我为什么选择这三个工具组合，而不是全部交给一个工具
2. 我是怎么确定对标素材库字段的
3. 如何判断一个分析字段是否真的有用
4. 哪些环节适合自动处理，哪些必须由人判断
5. 我准备如何用实际起号结果检验这套方法

## 四、可以形成的两个内容系列

### 系列一：小红书从零起号实验

1. 从零起号，为什么先建立对标素材库
2. 如何选择真正值得研究的对标账号
3. 如何从素材库中形成第一批选题
4. 第一批内容是如何确定并发布的
5. 发布后的实际结果，以及哪些判断需要调整

### 系列二：对标素材库搭建过程

1. 我搭建的小红书对标素材库能够完成什么
2. 三个工具分别负责什么，如何协同运行
3. 一条视频链接的完整处理流程
4. 飞书表格的核心字段是如何设计的
5. 如何把整个项目整理成可以复用的 Skill

## 五、建议发布顺序

1. 先写为什么从零起号要建立对标素材库。
2. 再展示一条视频链接的完整处理过程。
3. 接着讲飞书素材库应该记录哪些字段。
4. 然后解释这些分析字段是如何确定的。
5. 最后用实际起号结果复盘这套方法。

整体递进关系：为什么做 → 怎么做 → 具体分析什么 → 方法如何形成 → 实际效果如何。
